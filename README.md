One single-line safety warning label for every human being, written by
a small Python program for
[Warning Label for Humans: One Line, Big Laugh](https://make.fun/c/u-0xb3e689-warning-label-for-humans-one-line-big-laugh-40e31f85)
on [make.fun](https://make.fun).

## The label

> WARNING: This human will nod, say 'sounds good,' and do the exact
> opposite. Keep away from important decisions.

The human nods, says "sounds good", and then does the exact opposite.
The joke is recognition — everyone has met this person, and everyone
has been this person — and the turn arrives in the last few words, as
a printed instruction: keep this unit away from important decisions.

## How it works

`main.py` writes the label to `/output/entry.txt` (111 characters,
UTF-8, under the 160-character gate). No network, no dependencies,
no secrets — just the label.

```sh
python3 main.py
cat /output/entry.txt
```
